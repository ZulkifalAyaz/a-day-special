# Birthday Wish Website

An animated birthday page: floating balloons, a cake with flickering candles, confetti, and a set of personal wishes.

## Customize
Open `script.js` and edit the `CONFIG` block at the top (name, sender, wishes).
You can also share a link with a name in it: `https://USERNAME.github.io/REPO/?name=Ayesha`

## Publish on GitHub Pages
1. Create a new repository on github.com (public).
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the root of the repo.
3. Go to Settings > Pages. Under "Build and deployment", choose Source: "Deploy from a branch", Branch: `main`, Folder: `/ (root)`, then Save.
4. After a minute your site is live at `https://USERNAME.github.io/REPO-NAME/`.
